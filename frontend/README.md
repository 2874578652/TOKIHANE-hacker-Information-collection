# Frontend

赛博朋克风格的前端控制台（零依赖静态页面）。

## 启动

```bash
cd frontend
python3 -m http.server 5173
```

浏览器打开：

```text
http://localhost:5173
```

## 当前能力

- 扫描控制面板（目标、扫描参数、开关）
- VirusTotal 扫描开关（默认关闭；打开后会展开 API Key 输入框，必须填写你自己的 Key）
- 端口扫描模式选择（常用端口 / 全量端口 / 自定义端口）
- 端口扫描引擎选择（Auto / nmap；未检测到 nmap 时直接跳过端口扫描）
- 协议扫描开关（TCP / UDP 可单独启用，至少启用一个）
- 端口扫描总开关（打开展开高级端口选项，关闭收起并跳过端口扫描）
- 右侧开关与配置区分离：详细配置统一在 `MODULE CONFIG SPACE` 独立区域展示
- 证书透明度日志（CT）独立开关
- 被动/历史 DNS 独立开关
- ASN/C 段扩展独立开关
- Web 资产枚举独立开关（爬虫 / JS 接口 / 敏感路径 / 目录探测 / ffuf）
- 服务风险关联独立开关（CPE/CVE / 弱配置检查）
- 内网扫描独立开关（私网 IP + CIDR 输入）
- 终端风日志输出与动效
- 结果摘要 + 原始 JSON 展示
- `RESULT SNAPSHOT` 关键情报提取（目标、DNS、WHOIS、技术栈、IP端口服务、VT统计）
- `停止扫描`：扫描中一键停止（需要后端 API）
- `下载结果`：仅下载“真实扫描完成后”的 JSON（不下载本地加载文件）
- `一键清空`：清空当前扫描结果与日志，便于下一次扫描
- 彩虹高亮风格扫描进度条
- 支持直接加载 `report.json`
- 支持填写后端 API 地址后发起真实任务扫描

## 对接后端

前端 `Backend API` 填写：

```text
http://127.0.0.1:8000/api/scan
```

后端需要先启动 API 服务，否则无法执行真实扫描。

## 开发 / 生产自动切换

前端已内置自动模式：

- 开发环境（`localhost` 或 `127.0.0.1`）：默认 `http://127.0.0.1:8000/api/scan`
- 生产环境：默认 `${当前站点}/api/scan`

你仍可以在输入框手动改成任意后端地址进行联调。
