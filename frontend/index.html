API Workflow

Designed around how your backend actually runs scans.

The website now follows the same lifecycle as the API: submit a job, poll it, stop it if needed, then drill into the final report.

01

Create Job

Send a target and module selections to POST /api/scan and receive a queued job id.

02

Poll Status

Read queued, running, stopping, completed, failed, or canceled states from GET /api/scan/{job_id}.

03

Control Runtime

Abort long jobs through POST /api/scan/{job_id}/stop when you need to reclaim the pipeline.

04

Explore Report

Review DNS, web assets, IP scan, service risk, and raw JSON in the same control surface.
